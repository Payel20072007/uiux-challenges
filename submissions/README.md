📁 Design Submissions

Welcome to the submission space of our UI/UX Learning Hub!

This folder is where all members contribute their work for the design challenges assigned by the UI/UX Lead.

Every member is encouraged to submit their own work, document their design decisions and share their creative process.

🎯 Purpose
Maintain an organized record of design submissions.
Showcase individual creativity and design approaches.
Encourage learning through shared work.
Practice basic GitHub collaboration.
Keep all challenge submissions in one place.
📂 Folder Structure

Each member should create a personal folder and organize submissions challenge-wise.

```text
submissions/
│
├── README.md
│
├── member-name/
│   ├── challenge-01/
│   │   ├── README.md
│   │   ├── preview.png
│   │   └── screens/
│   │       ├── screen-01.png
│   │       └── screen-02.png
│   │
│   └── challenge-02/
│       ├── README.md
│       └── preview.png
│
└── another-member/
    └── challenge-01/
        └── README.md
```
📝 What Should Each Submission Include?

Every challenge submission should contain:

Figma Link – Link to your original design or prototype.
Preview Image – A screenshot representing your design.
Design Description – A short explanation of your solution.
Design Decisions – Explain your colors, typography, layout or components.
Learning Experience – Something interesting you learned while completing the challenge.
📌 Naming Guidelines

Keep folder and file names simple and consistent.

Use your GitHub username for your personal folder.
Use the challenge number for each challenge folder.
Use meaningful names for screenshots.
Avoid spaces and special characters in file names.

Examples:
```text
rahul/
challenge-01/
login-page-preview.png
```
🤝 Submission Guidelines
Submit only your own original work.
Keep your files organized.
Make sure your Figma link is accessible to the authorized reviewers.
Do not modify another member's submission.
Follow the submission process described in resources/github/submission-guide.md.
Be respectful when sharing and discussing design work.
💜 Let's Build Together

Every submission represents an opportunity to explore, experiment and improve.

Don't worry about making everything perfect. Focus on learning, creativity and consistency.

Create with curiosity. Share with confidence. Grow together! 🚀
