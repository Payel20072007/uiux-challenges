## GitHub – Our Collaboration Space ##

Welcome to our GitHub space!
As part of our UI/UX learning journey, we'll be using GitHub to organize design challenges, share our work and maintain a record of our creative progress.
You don't need to be a developer to use GitHub. We'll use it as a simple collaboration and project-sharing platform.

## Why Are We Using GitHub? ##
- To keep our design assignments organized.
- To maintain a collection of our design work.
- To document our creative process.
- To become familiar with repositories, commits and Pull Requests.
- To experience a collaborative workflow used by many professional teams.

## Some Basic Terms ##
- Term	Simple explanation
- Repository:	A place where project files and documentation are stored.
- Fork:	Your own copy of someone else's repository.
- Branch:	A separate working version of a project.
- Commit:	A saved record of your changes.
- Pull Request:	A request to add your changes to the original repository.
- README:	A document that explains a project.
  
## How We Use This Repository ##
Our organization will contain design challenges, resources and member submissions.
Each challenge will have its own instructions and submission requirements.

Members will work on their designs in Figma and use GitHub to submit their project documentation and exported previews.

Community Expectations
Keep your submissions organized.
Use meaningful file and folder names.
Write clear commit messages.
Respect other members' creative work.
Don't modify another member's submission.
Give constructive feedback.
Keep your Figma links accessible to authorized reviewers.

Remember
GitHub is simply another tool in our creative workflow.
Our main focus is learning UI/UX, exploring ideas and becoming better designers together.
Design. Document. Share. Grow.
